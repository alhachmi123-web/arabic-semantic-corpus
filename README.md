# المدونة المفتوحة للهندسة الدلالية العربية (Arabic Semantic Corpus)

مستودع بيانات مفتوح المصدر يهدف إلى بناء قاعدة بيانات ذهبية (Gold Standard Corpus) للنصوص العربية، مُهيكلة وفق معيار **«الهندسة الدلالية والتداولية»** المتحرر من العوامل الافتراضية والمبني على الأقطاب الخطابية وموجهات الحدث.

المشروع حالياً في مرحلة **مراجعة بحثية وتطويرية أولية** قبل النشر الرسمي على استضافة عامة، ويضم **2000 عينة ذهبية** مجتازة للتحقق.

## أهداف المشروع
- توفير بيانات تدريبية عالية الدقة لنماذج معالجة اللغات الطبيعية العربية (Arabic NLP) والنماذج اللغوية الكبيرة (LLMs).
- تمثيل الخطاب العربي بصيغة `JSON` قياسية قابلة للتحويل المباشر إلى ثلاثيات معرفية (`RDF Triples`) ورسوم معرفة (`Knowledge Graphs`).
- إشراك الباحثين اللسانيين والمطورين في مراجعة المدونة وتوسيعها وفق معايير تحقق برمجية صارمة.

## الحالة الحالية للمشروع
- **عدد العينات المعتمدة:** 2000 عينة ذهبية.
- **حالة الفحص:** اجتازت جميع العينات الفحص أمام المخطط القياسي والتدقيق اللغوي والصرفي دون أخطاء.
- **مرحلة المشروع:** مراجعة من الباحثين والمطورين قبل النشر الرسمي.

## هيكل المستودع
- `schema/`: المخطط البرمجي القياسي (`arabic-semantic-engine.schema.json`).
- `corpus/`: ملفات المدونة الذهبية (`seed_gold`) والحزم والملفات المجمّعة (بما في ذلك عزل الألف عينة الأولى ومساهمات المجتمع إن وُجدت).
- `scripts/`: أدوات المعالجة والتحقق والبناء والتجميع (`validator.py`، `lexical_checker.py`، `batch_builder.py`، `build_corpus_bundle.py`، `project_audit.py`، وغيرها من سكربتات المشروع).
- `web/`: الواجهة المحلية لاستعراض المدونة (`index.html` و`app.js`).
